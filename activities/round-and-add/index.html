Round Each Addend, Then Add

Estimate a sum: round each number first, then add the rounded numbers.

How it works
  1. Endpoints. Find the two neighboring multiples of the rounding place. The number sits between them.
  2. Midpoint. Find the number exactly halfway between the endpoints.
  3. Plot. Move the marker to show where the number is on the number line.
  4. Round. Choose the closer endpoint. If the number is exactly on the midpoint, round up to the higher endpoint.
  5. Estimate. Add the two rounded numbers.
